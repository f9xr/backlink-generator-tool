    How it works: modes for every workflow

    IFrame mode (stealth loading)

    Quietly opens sources in hidden iframes (powered by the included stealth stylesheet). Ideal for continuous, low-noise link indexing and crawl discovery.

    Popup/Tab mode (visible load)

    Opens endpoints in a small popup or a browser tab. Select Reuse same window/tab for efficiency. Important: allow pop-ups for this site to make Popup/Tab work reliably.

    Ping mode (proxy fetch)

    Sends requests through rotating proxies, quickly moving to the next endpoint once a successful response is detected-fast path to instant indexing triggers and archive submit pings.
