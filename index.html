    Frequently asked questions

    Straight answers about what this free backlink generator does, what it cannot do, and how to run it safely.

    Ask a question
    Is this backlink generator really free?

    Yes. The tool is free, needs no account and has no paid tier or credit limit. The engine, the template library and the exporters are static files served to your browser.

    If a page ever asks you to pay for this generator, you are on the wrong site.

    Do these submissions count as real backlinks?

    Most are index discovery, ping, share and archive signals. They help crawlers find a URL faster and create additional paths to the page.

    They are not a replacement for editorial links from sites that choose to cite you. Read the free versus paid comparison before you set expectations.

    Do I need a server, account or API key?

    No. Templates are static JSON files and every request opens from your own browser session. There is no backend, no login and nothing stored on a server.

    Your only stored preference is a first-party cookie that remembers the mode, concurrency and batch limit you picked.

    Which delivery mode should I use?

    IFrame is the quietest default and handles the largest batches. Popup or Tab works for targets that refuse to load in a frame. Ping checks reachability through a public CORS proxy.

    Details for each mode are in the delivery modes section and the full guide.

    Can I download the generated links?

    Yes. The Download links menu exports the list from your last run as CSV, Excel (XLS), PDF or plain TXT. Every file is generated in your browser, so no URL leaves the page.

    Does it work for YouTube links?

    Yes. When the URL contains a video ID, the generator switches to the YouTube template list so links carry the video and timestamp instead of a generic page path.

    Why do some targets show a cross?

    Endpoints rate-limit, block frames, sit behind long redirect chains or have simply gone offline. Lower concurrency, shuffle templates, or run the same page again later.

    A green tick only means the target loaded. It is not proof that a link or listing was created.

    Is it safe for a brand new website?

    Keep runs small and gradual. Start with the IFrame mode at low concurrency, target your best pages, and never point thousands of requests at a domain you do not own.

    If a target looks like a spam farm, skip it. Volume is not a ranking strategy.

    What data leaves my browser?

    Only the requests the tool opens: the generated backlink URLs, an optional thum.io preview of the URL you typed, and, only if you tick the box, a Wayback Machine submission.

    No analytics or tracking scripts are loaded. The full detail is in the privacy policy.

    How do I report a bug or a bad target?

    Use the report a problem page. Include the page URL, the mode, the browser and what you expected to happen. Reports about dead or unsafe endpoints are reviewed first.
