    How it works

    1. You enter one URL. The engine validates it and builds a placeholder map (host, path, query, video ID).
    2. Every URL template in the JSON dataset is filled in with your page, so links point at exactly that page.
    3. The chosen delivery mode opens each target once, waits for it to load, and records whether it did.
    4. Copy the shareable link to re-run the same URL later, or download the full list as a text file.

    Delivery modes

    IFrame

    Loads each target in a hidden 1×1 frame. Quietest mode, works without popup permission, and the best default for bulk runs.

    Popup / Tab

    Opens real windows. Use it when an endpoint refuses to load in a frame. Allow pop-ups for this site first.

    Ping

    Requests each URL through a public CORS proxy and records whether it answered. Fast, but a proxy error page still counts as a response.

    Archive submissions

    Archive endpoints are part of the normal template list: each one asks a snapshot service to fetch the page, which gives crawlers another URL to discover. The Wayback Machine copy is separate and only runs when you tick its box.

    Frequently asked questions

    Is this really free, and do I need an account?

    Yes — free, no account. The engine, the templates and the export are all static files served to your browser.

    Do these submissions count as real backlinks?

    Most are index-discovery and ping signals: they help crawlers find a URL faster. Treat them as a discovery helper, not a replacement for editorial links.

    Why do some targets show ✖?

    Endpoints rate-limit, block frames or sit behind a redirect chain. Lower concurrency, shuffle templates, or run again later.

    What data leaves my browser?

    Only the requests the tool opens: the generated backlink URLs, the optional thum.io preview of the URL you typed, and — only if you tick the box — a Wayback Machine submission.
